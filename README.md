## Admin Dashboard

## Description
A responsive admin dashboard built using HTML and CSS.

## Features
- Responsive top navigation bar
- Sidebar navigation
- Four statistics cards
- Two chart sections
- Recent users table
- CSS Grid layout
- Mobile responsive design

## Technologies
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- Git and GitHub

## How to Run
1. Clone the repository.
2. Open the project in VS Code.
3. Open index.html using Live Server.
